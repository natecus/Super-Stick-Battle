# Robot

Boss 1 in the Robot → Ninja → Cheese → Dave ladder. Available immediately. Victory unlocks the separate player configuration for both local players, saved in the existing browser progress.

Beat Robot to recruit him. Fire quick laser bolts and activate Flight boots for four seconds of controlled flight (five for the boss). After a brief automatic takeoff, hold W / up arrow to rise, S / down arrow to descend, and release to hover. Horizontal movement and attacks remain available. Robot can still be hit, and gravity resumes when the timer expires.

The boss has 800 HP, attack armor, passive ultra charge, and enrage. The player has normal size, three lives, interruptible attacks, and combat-earned charge.
