# Clubber

Based on `reference.jpeg`: an angry, muscular stick figure with a heavy club.

Club smash is a slow, powerful melee hit. Earthquake requires standing on a platform; after a short windup it damages every grounded enemy on that same platform. Airborne fighters and enemies on other platforms are safe. In Boss Battle, teammates are never damaged.

Edit `character.json` for stats and appearance. See [the character guide](../../../docs/ADDING-CHARACTERS.md).
