# Boxer

Based on the supplied Boxer drawing: smiling round head, rectangular six-pack torso, stick limbs, and oversized gloves. The shared canvas rig animates the portrait, punches, and thrown glove without loading the original photograph.

Available immediately to both players. Punch is a short-range melee attack; Glove throw launches one large projectile in the facing direction. Both respect teams and normal damage/knockback rules.
