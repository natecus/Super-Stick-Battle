# Ninja

Boss 4 in the Dave → Cheese → Robot → Ninja ladder. Defeat robot to challenge this encounter. Victory unlocks the separate player configuration for both local players, saved in the existing browser progress.

Beat Ninja to recruit him. Quick katana cuts and a spinning blade flurry trade reach and weight for speed.

The boss has 950 HP, attack armor, passive ultra charge, and enrage. The player has normal size, three lives, interruptible attacks, and combat-earned charge.

No Ninja reference image was present when this pack was created; the masked katana doodle uses the shared vector rig.
